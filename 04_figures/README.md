## 📐 Formats & conventions

- **Cartes principales** : JPEG haute résolution (min. 1200 px de large)
- **Graphiques** : PNG avec fond transparent quand pertinent
- **Nommage** : `theme_description.extension` (sans espaces, minuscules)
